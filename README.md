# Wavelet and Gaussian kernels for traffic sign classification

This repository accompanies *Bandwidth Matching and Coordinate Sensitivity of Wavelet and Gaussian Kernels for Traffic Sign Classification*.

See the [reproduction instructions](study/README.md) for the environment, dataset downloads and commands. The study directory contains the experiment scripts, protocol versions and dependency lists. The manuscript's Online Resources contain the archived experimental records, predictions, embeddings and model bundles.
